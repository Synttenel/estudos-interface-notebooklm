Por trás da concepção dos prompts:

Acredito que o assunto é bem pessoal para mim, sempre gostei do tópico, sempre quis fazer interface bonitas, funcionais e modernas. Fiz 3 perguntas mais imparciais e 1 pergunta mais parcial, prevendo uma variedade nas respostas. Mesmo parecendo ajudar, ser parcial na hora de gerar um prompt acaba tedenciando a IA ser mais leve e desviar do que você realmente quer ouvir, sendo assim um prompt imparcial vai ajudar na maioria das vezes. A IA foi bem didática e utilizou das fontes providenciadas a ela.
